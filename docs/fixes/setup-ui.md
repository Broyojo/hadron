# Clarify the setup window

Present Steam status in a card, make setup/open Steam the primary action, explain what setup
does, and move removal to a separate footer. The setup/repair operations themselves remain
unchanged. The first-run macOS App Management hint remains visible through the existing
permission-error guidance.

Swift typechecking was performed on macOS 27.0.1. The app was not installed as a release and
visual acceptance across appearance/accessibility settings is still pending. This UI change
is independent of game compatibility fixes and can be reviewed or deferred separately.
